# 颤振诊断 Skill（v1.0.0 · 历史归档）

## 与现行 v3.0.0 的主要差异

| 项 | 本文件 (v1.0.0) | 现行 (v3.0.0) |
|----|----------------|---------------|
| 诊断模式 | 多层融合（数据/特征/决策层） | 单一模式（SAE + Stacking） |
| CSV 第 2 列 | 主轴振动（无 Z 轴） | X 振动（三轴 X/Y/Z） |
| 最小采样点 | ≥ 512 | ≥ 256 |
| 分段大小 | — | 256 点/段 |
| 实时监控 | z-score 基线偏离 | 支持（复用 baseline_stats.json，需先运行 train_fusion_model） |
| 模型文件 | sae_model.pth / scaler.pkl / fusion_model.pkl / baseline_stats.json | + scaler16.pkl（两级归一化）；监控模式另需 baseline_stats.json |

## 功能描述（旧版）

对去噪后的振动传感器和三向力信号进行多层融合分析（数据层→特征层→决策层），诊断加工状态是否发生颤振，并输出可解释的诊断报告。

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `csv_path` | string | 是 | CSV文件路径 |

## CSV格式要求

- 第1列: 时间 (秒)
- 第2列: 主轴振动
- 第3列: X轴振动
- 第4列: Y轴振动
- 第5列: 三向力合力

**采样点数**: 至少512点

## 调用方式

```python
from chatter_diagnosis_skill import diagnose_csv

report = diagnose_csv(csv_path)
print(report)
```

或命令行:
```bash
python chatter_diagnosis_skill.py <csv_path>
```

## 输出格式

诊断报告包含以下部分:
1. **信号概况**: 时长、各通道统计
2. **诊断结果**: 状态分类 (稳定/轻微颤振/严重颤振) + 置信度
3. **分析依据**: 关键特征偏离分析 (与基线对比)
4. **工艺建议**: 针对性的切削参数调整建议

## 前置条件

1. **模型文件已训练**: `models/` 目录下需存在:
   - `sae_model.pth`
   - `scaler.pkl`
   - `fusion_model.pkl`
   - `baseline_stats.json`

2. **依赖包已安装**:
   ```bash
   pip install -r requirements.txt
   ```

3. **训练数据已准备**: 如果模型未训练，需先运行:
   ```bash
   python train_all.py
   ```

## 技术架构

- **特征提取**: 50维 (振动3×15 + 力×5)
- **特征层融合**: SAE稀疏自编码器 (50→16维)
- **决策层融合**: 6基分类器 + Stacking (LightGBM, CatBoost, SVM, ExtraTrees, KNN, MLP)
- **分类目标**: 三分类 (稳定, 轻微颤振, 严重颤振)
- **可解释性**: 基于特征偏离基线的 z-score 分析

## 错误处理

- 信号过短 (<512点) → 提示增加采样时间
- 模型文件缺失 → 提示运行 `python train_all.py`
- CSV格式错误 → 提示检查列数和格式
